## Python – Exceptions
Holberton School – Higher Level Programming

📘 Overview
This project introduces Python exceptions, one of the most important mechanisms for handling unexpected events and errors in programs.
You will learn how to distinguish errors from exceptions, how to raise and catch exceptions properly, and how to write safe, robust Python code.

All requirements and tasks come from the official Holberton project page .

🎯 Learning Objectives
By the end of this project, you should be able to explain, without using Google:

General Concepts
Why Python programming is awesome

The difference between errors and exceptions

What exceptions are and how to use them

When exceptions should be used

How to correctly handle exceptions

Why catching exceptions is useful

How to raise built‑in exceptions

When and how to implement clean‑up actions after an exception
