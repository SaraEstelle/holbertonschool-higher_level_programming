Python – More Data Structures: Set, Dictionary
Holberton School – Higher Level Programming

📘 Overview
This project expands your understanding of Python data structures by introducing sets, dictionaries, and functional programming tools such as lambda, map, filter, and reduce.
You will learn how to manipulate collections efficiently, choose the right data structure for a given problem, and write more expressive Python code.

All requirements and tasks come directly from the official Holberton project page ().

🎯 Learning Objectives
By the end of this project, you should be able to explain, without using Google:

General Concepts
Why Python programming is awesome

What sets are and how to use them

The most common set methods and how to use them

When to use sets vs. lists

How to iterate through a set

What dictionaries are and how to use them

When to use dictionaries vs. lists or sets

What a dictionary key is

How to iterate over a dictionary

What a lambda function is

What map(), filter(), and reduce() do

These objectives are listed on the project page ().
