## Python – Data Structures: Lists, Tuples
Holberton School – Higher Level Programming


📘 Overview
This project introduces two essential Python data structures: lists and tuples.
You will learn how they work, how to manipulate them, and when to use one over the other.
The tasks progressively build your understanding of sequences, list operations, tuple packing/unpacking, and Pythonic idioms such as list comprehensions.

All project details are based on the official Holberton page .

🎯 Learning Objectives
By the end of this project, you should be able to explain, without using Google:

General Concepts
What lists are and how to use them

Differences and similarities between strings and lists

The most common list methods and how to use them

How to use lists as stacks and queues

What list comprehensions are and how to use them

What tuples are and how to use them

When to use tuples vs. lists

What a sequence is

What tuple packing is

What sequence unpacking is

What the del statement does and how to use it

These objectives come directly from the project page .
